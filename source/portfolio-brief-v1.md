# 9. Desterrocore — Visual & Frontend Design System

This section is intended to guide frontend generation and should be treated as the core aesthetic specification of the portfolio.

## Overall Mood

The visual identity should combine:

- Hacker / Unix terminal culture
- Senior software engineering
- Underground technical aesthetics
- Florianópolis / Desterro
- Coastal geography
- Concrete, bridges, urban infrastructure
- Independent cinema
- Hip-hop visual language
- Screen-print / zine / poster textures
- Slight cyberpunk influence
- Brazilian countercultural energy
- Minimalism beneath the visual grit

The target is **not** generic cyberpunk.

It should feel like:

> Unix terminal + independent cultural poster + southern coastal city + brutalist engineering documentation.

The website should remain highly usable, legible, and professional despite the raw aesthetic.

---

## Core Visual Principle

**Clean structure, dirty surface.**

The layout itself should be disciplined, grid-based, spacious, and technically precise.

Texture, distortion, terminal fragments, grain, scanlines, and cultural references should exist primarily as surface treatment and detail.

Do not make the content difficult to read.

---

## Color Palette

### Background

`#090909` — near-black

Primary canvas color. Avoid pure black where possible.

### Foreground / Paper

`#E7DFCF` — warm off-white / old paper

Used for primary text, diagrams, outlines, and light visual elements.

### Signal Orange

`#E85D04` or `#F26419`

Primary accent.

References sunset, sodium street lighting, warning systems, graffiti paint, screen printing, and the orange sun in the Desterrocore avatar.

### Terminal Green

`#7CFF4F` or a slightly muted equivalent

Secondary accent only.

Used sparingly for:
- terminal prompts
- status indicators
- code metadata
- command-line details
- hover states

### Muted Gray

`#77736C`

For metadata, timestamps, separators, secondary copy, and disabled states.

### Optional Deep Concrete

`#171717`

For cards, panels, code sections, and elevated areas.

---

## Color Rules

Orange should carry identity.

Green should carry machine / terminal semantics.

Do not use orange and green equally.

Recommended ratio:

- 70% near-black / dark surfaces
- 20% off-white / neutral content
- 8% orange
- 2% terminal green

Avoid bright blue, purple cyberpunk gradients, neon pink, or glossy synthwave palettes.

---

# 10. Typography

## Primary Direction

The site should combine a **strong grotesk / industrial sans-serif** with a **monospace typeface**.

Recommended conceptual pairing:

- Headings: condensed grotesk, industrial sans, or brutalist display face
- Body: highly legible neutral sans-serif
- Metadata / labels / code: monospace

Examples of suitable open-source directions:

- Space Grotesk
- IBM Plex Sans
- Inter
- Archivo
- Barlow Condensed
- IBM Plex Mono
- JetBrains Mono
- Source Code Pro

The implementation should favor web-safe performance and readability over novelty.

---

## Typography Behavior

Large headings can use:

- uppercase
- compressed spacing
- strong weight
- occasional italic or oblique emphasis
- oversized section numbers

Example:

`01 / SYSTEMS`

Metadata may resemble terminal output:

`[status: online]`
`~/projects/culture`
`last_deploy: 2026`

Avoid making all copy monospace. That quickly becomes gimmicky and difficult to read.

- blinking terminal cursor
- subtle scanline motion
- text reveal resembling logs

- excessive scroll-jacking
- continuous glitch
- dramatic 3D effects
- long cinematic transitions
- animations that slow navigation

The website should feel fast.

# 29. Design Do / Don't

## Do

- Use near-black backgrounds.
- Use orange as the dominant accent.
- Use green only for terminal semantics.
- Keep typography large and confident.
- Use strong grids.
- Use monospace for metadata.
- Use subtle grain and print texture.
- Let coastal / Desterro imagery appear abstractly.
- Use engineering diagrams.
- Treat cultural projects with poster-like visual energy.
- Keep performance excellent.
- Make mobile layouts extremely readable.

## Don't

- Do not build a generic neon cyberpunk site.
- Do not turn the whole interface into a fake terminal.
- Do not use Matrix-style green everywhere.
- Do not overuse hacker stereotypes.
- Do not use glassmorphism.
- Do not use glossy gradients.
- Do not use generic SaaS cards.
- Do not use excessive border radius.
- Do not hide content behind animation.
- Do not sacrifice accessibility for aesthetics.
- Do not make Florianópolis look like a tourism brand.
- Do not separate engineering and culture into unrelated personalities.
